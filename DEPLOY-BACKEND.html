Un seul admin, tous les membres

Netlify garde le site. Render + MongoDB Atlas gardent les comptes. L’admin voit alors tout le monde.

Routes API créées

  • POST /api/register — inscription
  • POST /api/login — connexion
  • POST /api/withdraw — demande de retrait
  • GET /api/admin/members — tous les membres
  • GET /api/admin/withdrawals — tous les retraits
  • PUT /api/admin/withdrawals/:id — valider / refuser un retrait

1. MongoDB Atlas (gratuit)

1 Créez un compte sur mongodb.com/cloud/atlas

2 Créez un cluster M0 Free

3 Database Access : utilisateur + mot de passe

4 Network Access : ajoutez 0.0.0.0/0 (Render)

5 Connect → Drivers → copiez l’URI :
mongodb+srv://USER:MOTDEPASSE@cluster0.xxxxx.mongodb.net/gta?retryWrites=true&w=majority

2. Render (backend)

1 Mettez ce projet sur GitHub (index.html à la racine)

2 dashboard.render.com → New → Web Service

3 Réglages :

  • Runtime : Node
  • Build : npm install
  • Start : npm start
  • Plan : Free

4 Variables d’environnement :

NODE_ENV=production
MONGODB_URI=mongodb+srv://USER:MOTDEPASSE@cluster0.xxxxx.mongodb.net/gta
CORS_ORIGIN=https://iridescent-cactus-543a96.netlify.app

5 Deploy. Notez l’URL : https://xxxx.onrender.com

Testez : https://xxxx.onrender.com/api/health doit afficher "cloud": true

3. Relier Netlify au backend

Dans js/api-config.js, mettez l’URL Render :

window.GTA_API = 'https://xxxx.onrender.com';

Puis redéployez le ZIP sur Netlify.
